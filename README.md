## Overview

Eric Money is a financial management application that allows users to:
- Create and manage transactions.
- Register different users, enabling them to create and manage their own transactions.
- Categorize transactions into **income** and **expense**.
- Generate detailed financial reports based on transaction data.

The app is built using **React** for the frontend and utilizes **Redux** for efficient state management.  
It is connected to a **backend** powered by:
- **Docker**
- **Node.js**
- **PostgreSQL**

The backend source code is published on [GitHub](https://github.com/Gabriel-mdv/eric-finance-coa-bn1).

## Key Features

1. **User Management**
   - Create user accounts.
   - Log in with phone and password to manage personal finances.
   
2. **Transaction Management**
   - Add new transactions.
   - Categorize transactions as **income** or **expense** for better organization.

3. **Reporting**
   - Generate comprehensive reports to get insights into your income and expenses.
